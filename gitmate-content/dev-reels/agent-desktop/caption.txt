Your AI agent can write code... but it can't click a single button on your desktop. 🖱️

agent-desktop by Vercel Labs (10k+ ⭐ on GitHub) gives any AI agent computer use:
→ No screenshots, no pixel guessing: it reads the app's accessibility tree (the same one screen readers use)
→ Every element gets a ref. Your agent clicks the ref, then snapshots again to check it worked
→ Headless by default: actions go through the accessibility API without moving your pointer or stealing focus
→ 56 commands: click, type, scroll, drag, windows, clipboard, notifications and more
→ Works with any agent harness (the CLI prints JSON, plus a C library for in-process calls)

✅ Free + open source (Apache-2.0)
✅ macOS, Windows and Linux: npm install -g agent-desktop
