→ Reads your database metadata and builds an ontology: what every table, metric and join actually means
→ Ask in plain English: it writes the SQL, runs it and shows every step, so you can check the answer
→ If your data can't answer the question, it tells you instead of making something up
→ Plugs into any agent harness through MCP, CLI and API
→ Comes with a web UI for chat, data catalog and analytics

✅ Free + open source (Apache-2.0)
