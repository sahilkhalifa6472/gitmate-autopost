# git.mate reel ideas from the owner

The daily task reads this first. It uses the oldest idea that isn't done yet (top to bottom), and marks it `[x]` with the date and slug when the reel is made.
If the list is empty, it picks a trending repo itself.

Format: `- [ ] <repo link / news link / topic> (added YYYY-MM-DD) - owner's note, if any`
