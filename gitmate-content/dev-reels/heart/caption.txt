Forget flowers. This is how a developer says "I love you" ❤️

4R022 Heart, built by @kosemen.00, is a tiny Python + Qt app that plays a cinematic love scene:
→ A heart is drawn in light, then filled with "I love you" in 30 languages
→ It glows and beats, full screen on every monitor you have, all at once
→ About 49 seconds, then it fades out and closes by itself
→ Fully offline: no network, no data collected
→ Made for birthdays, anniversaries, proposals and surprises

Run it: clone the repo → pip install -r Build/requirements.txt → python Main/Main.py
