- 2026-10-24 owner RULE for every @git.mate reel: do NOT copy the previous reels' scene components (pills, dial, hex nodes, ring counter, oval, sliding cards). The owner's reference video was only for the feel: 3D, kinetic text style (blur typing + serif italic accents), black & white. Every UI element must be newly designed for that repo's content, so it gives a "wow" reaction.
- **Why:** the owner felt the 2 light reels (security-audit-light, php2shell) looked the same; they want each reel to feel fresh and made for its topic.
- **How to apply:** before writing reel.html, list the repo's own visual idea and invent 5-8 components from it. Where the repo is a tool/skill that makes visuals, use the tool itself to make the artifacts (e.g. Anatomy reel: built a custom "Follow · @git.mate" machine with its kit, and recorded its example machines frame-by-frame with Playwright page.clock). Keep the shared shell only (camera engine, typing helpers, brand bead, Comment GITMATE + Follow ending, audio mix).
- Example: /mnt/project-files/dev-reels/anatomy/ (blueprint sheet frame, extruded 3D letters, flip cards, magnifier loupe, slicing exploded card, hanging metal tags). Related: [[dev-repo-page-style]]
