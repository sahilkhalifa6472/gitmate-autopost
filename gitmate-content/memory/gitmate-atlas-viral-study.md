Study done 2026-11-15 from owner's Instagram insights + dashboard API (22 posted reels).
- Atlas #19 (posted 2026-11-11): 111.7k views, 88.8k viewers, avg watch 16s of 34.6s (others 6-9s), skip rate 28.1%, saves 5.7k (6.3%), shares 2.2k (2.4%), 611 comments, 1,221 follows, 99.3% non-followers, 86% Reels tab. Audience India 36%, age 18-34 = 87%. Next best reels: Floci 4.6k, Sherlock 4.2k, ThinkRail 3.9k.
- Why: (1) hook = a daily pain everyone has ("Why is Explorer STILL searching for a file you saved yesterday?") + REAL footage of the pain in the first 2s, not the repo name; (2) mass audience (every Windows user) vs AI-agent niche tools; (3) a visual app with UI to show; (4) "replace the thing you hate, free" = save/share trigger; (5) one-click install (Microsoft Store), no terminal needed; (6) solo-dev story.
- Rules for picks: prefer free apps normal people use daily (Windows/Mac/Android/browser replacements) with real UI footage; hook with the pain, name the repo only at ~3-4s; say "free" + easiest install; keep under 35s.
