# git.mate autopost

Instagram auto-posting dashboard for @git.mate (Next.js on Vercel).

- Dashboard: next post, today's plan, views per reel, best time windows
- Queue: upload reels, reorder, post now, skip
- Logs: every run, post, insight check and error
- Settings: Instagram token, schedule (New York time, 1/day), pause

Setup steps: see SETUP.md. Every push to `main` is deployed by Vercel automatically.
